📖 Book of Answers

A beautiful desktop oracle built with ESP32-S3.

Book of Answers is an open-source hardware project that transforms the timeless “Book of Answers” concept into a physical desktop companion.

Ask a question. Take a deep breath. Press the button.

The device responds with a thoughtful message—not to predict the future, but to encourage reflection and help you see your situation from a different perspective.

This project is part of Creative Lab, a collection of AI-powered hardware experiments.
